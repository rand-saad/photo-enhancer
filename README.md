# توضيح الصور بالذكاء الاصطناعي

**الموقع المباشر (كاميرا + محرر):** https://rand-saad.github.io/photo-enhancer/

موقع يوضّح الصور ويشيل التشويش باستخدام موديل **Real-ESRGAN x4plus**.

## الملفات
- `index.html` — نسخة سريعة تشتغل بالمتصفح بدون سيرفر وبدون رفع الصورة. افتحيها مباشرة بالمتصفح.
  - **كاميرا احترافية:** شبكة الأثلاث، EV، تقريب، فلاش، مؤقت 3/10 ثواني، تبديل أمامية/خلفية، ضغطة للتركيز، ومعاينة مباشرة للطابع. الضغطة على الشخص تصير هي نقطة التركيز لتغبيش الخلفية.
  - **طابع احترافي:** بورتريه (تغبيش خلفية)، سينمائي، فيلم، درامي، ساعة ذهبية، طبيعة، طعام / منتج.
  - **ضبط يدوي:** تعريض، تباين، ظلال، إضاءات، بهتان الأسود، تشبّع، دفء، طابع لوني، وضوح، حدّة، إزالة تشويش، تغبيش خلفية، تظليل أطراف، حبيبات فيلم.
  - مقارنة قبل/بعد، مدرّج لوني، وحفظ بالحجم الكامل أو ×2.
  - الكاميرا المباشرة تحتاج رابط HTTPS (مثلاً Space من نوع Static على Hugging Face، أو GitHub Pages). إذا ما تشتغل، الزر يفتح كاميرا التلفون العادية والصورة تنفتح بالمحرر.
- `app.py` — واجهة Gradio (رفع صورة، اختيار الجودة والحجم، مقارنة قبل/بعد، تحميل).
- `enhancer.py` — منطق التحسين: يحمّل الموديل مرة وحدة ويشغّله على مربعات (tiles) حتى ما تخلص الذاكرة.
- `requirements.txt` — المكتبات.

أوزان الموديل (67MB) تنزل تلقائياً من GitHub أول ما يشتغل الموقع، فلا ترفعيها.

## الرفع على Hugging Face Spaces
1. سوي حساب على huggingface.co.
2. New → Space → اختاري **Gradio** → Hardware: **CPU basic (free)**.
3. ارفعي الملفات الأربعة (`app.py`, `enhancer.py`, `requirements.txt`, `README.md`) من Files → Add file.
4. انتظري البناء (أول مرة ياخذ كم دقيقة)، وبعدها يطلعلك رابط يشتغل من التلفون.

## تشغيل محلي
```bash
pip install -r requirements.txt gradio
python app.py
```

## ملاحظات السرعة
- على CPU المجاني، صورة بوضع «متوازن» تاخذ تقريباً 2–4 دقايق.
- مع GPU (مثلاً ZeroGPU أو Colab) تنزل لثواني.

## أفكار للتطوير
- إضافة NAFNet لإزالة الضباب من الحركة.
- إضافة CodeFormer لتحسين الوجوه.
- تطبيق Flutter يرسل الصورة لنفس الموقع عبر الـ API (`/run`).
